LEONIDA — an offline guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI. Every trophy has its official name, description and grade, a guide written in our own words with steps and cited sources, a kind (story, missable, collectibles, activities, online), a missable flag, and a place in a six-stage roadmap to the platinum. The tracker saves your checklist in the browser (localStorage), with filters by kind, grade and status, a spoiler-safe mode that hides story trophy names until earned, and progress export/import.

## Run it

```sh
python3 -m http.server 8080 --directory app
```

Then open http://localhost:8080. No build step, no network needed — every file the app loads is inside `app/`.
